## Choices

- The copy lives in `content.ts` and in the HTML, so the page reads with JavaScript off (rule 2); a test keeps the two identical. Rejected: rendering the HTML from `content.ts` at build time, which adds a build step the spec doesn't need yet.
- The "Turn on JavaScript" notice is in the page and removed by `main.ts`, instead of a `<noscript>`: Chromium with scripting turned off through Playwright doesn't render `<noscript>`, so the test could not see it.
- The form's button is `type="button"` until phase 2a adds behaviour, so with JavaScript off it can never submit the email in a URL.
- Playwright now tests the production build through `vite preview` instead of the dev server: the first run against the dev server timed out once (cold start); against the build, two full runs passed.
