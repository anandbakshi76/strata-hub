## Choices

- The Menu button folds the links only when JavaScript is on (`.js` class), so with JavaScript off every link stays visible.
- The form's button stays `type="button"`; `form.ts` handles the click and stops Enter from submitting, so the email can never land in a URL.
- On phones the exploded still sits above the chapters; on wide screens it stays beside them (sticky). The scroll motion replaces this in phase 2b.
- "Recommended" on the Home bundle and one primary button among the cards, as DESIGN.md 5 says; the phase 1 review asked to confirm this (N4).
- The heading "Scroll to look inside" is kept as approved copy, styled as a small lead-in. Renaming it (phase 1 review N3) would change approved copy, so it is left for the person.

## Review fixes (after the independent review)

The fresh-session review (`docs/log/2026-11-20-phase-2a-independent-review.md`) found one Blocker, four Should fix and eight Notes. Tests for them were committed first and failed (a982fe1, output in `2026-11-20-phase-2a-review-tests-first-run.txt`).

- **B1 (Blocker):** with JavaScript off, Enter in the email field submitted the form as a GET request with the email in the URL (HTML implicit submission), breaking rule 4. My phase 1 assumption that a `type="button"` button was enough was wrong. Fixed: the fields sit in a `<fieldset disabled>` that `form.ts` enables, so with JavaScript off nothing can be typed or sent. Test: Enter with JavaScript off sends nothing and keeps the URL.
- **S1:** the Register interest buttons now put the focus in the email field (SPEC 5).
- **S2:** the header's blur (a glass effect) is gone (DESIGN.md 2).
- **S3:** no raw colours outside `tokens.css` (new tokens `--white`, `--header-bg`, `--hairline-dark`), checked by `web/styles.test.ts`; chapter names use `--stone-200`.
- **S4:** each form error has an outline alert icon, hidden from screen readers.
- **N1:** an open FAQ shows a minus. **N6:** the bundle ticks and dashes are silent for screen readers. **N4:** tests added for the stills under reduced motion and axe on the error state and the open phone menu. **N5:** screenshots are in `docs/log/img/`.
