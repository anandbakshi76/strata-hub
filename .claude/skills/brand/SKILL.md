# Brand and screens

- Use only the fonts, colours and surfaces in `docs/BRAND.md`.
- Every screen works with the keyboard alone, shows where the focus is, has text contrast of at least 4.5:1 and works 375px wide.
- Every list and form has empty, loading and error states. An error says what happened and how to fix it.
- Labels are plain English in sentence case. A button says what it does.
- If a requirement conflicts with these rules, don't choose: raise it as a concern for the person.
